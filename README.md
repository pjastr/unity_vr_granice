# unity_vr_granice

Projekt generowany maszynowo za pomocą Claude Code i modelu Opus 5.5.

Demo obsługi granic (Boundary / Guardian) sterowane kontrolerami Touch (`OVRInput`) dla Meta Quest 3S w Unity 6.3 LTS (6000.3.24f1).

Instrukcja konfiguracji, Build & Run przez USB i obsługi: [INSTRUKCJA.md](INSTRUKCJA.md)
